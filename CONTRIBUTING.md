# Contributing to FarsiForge

First off, thank you for considering contributing to FarsiForge! It's people like you that make FarsiForge such a great tool for the Persian localization community.

## Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check our [Issues](https://github.com/orgs/FarsiForge-dev/repositories) to see if someone has already reported it or requested it.

## Fork & create a branch

If this is something you think you can fix, then fork FarsiForge and create a branch with a descriptive name.

## Get the test suite running

Make sure to test your code before submitting a Pull Request.

## Implement your fix or feature

At this point, you're ready to make your changes! Feel free to ask for help; everyone is a beginner at first.

## Make a Pull Request

At this point, you should switch back to your master branch and make sure it's up to date with FarsiForge's master branch.
Then push your feature branch to your fork and submit a Pull Request!
