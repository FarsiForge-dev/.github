# Security Policy

## Supported Versions

Currently, only the latest release of FarsiForge tools is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within FarsiForge, please send an e-mail to amirwopi@gmail.com. All security vulnerabilities will be promptly addressed.
